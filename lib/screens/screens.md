# `screens/` 畫面頁面目錄簡介

`screens/` 目錄存放 **UniTrack Pro** 的所有主要功能畫面（UI Screens）。每個畫面對應主導覽列（`MainScreen`）中的一個主要功能分頁，並搭配 `ResponsiveLayout` 支援手機、平板與桌面端的自適應排版。

---

## 頁面檔案一覽

### 1. `dashboard_screen.dart` — 首頁總覽 (`DashboardScreen`)
* **功能定位**：使用者的個人化校園生活儀表板（Dashboard）。
* **主要內容**：
  * **今日校園生活總覽卡片**：串接 Cloud Firestore 即時課表資料流，自動根據當前系統時間與星期，純資訊動態呈現「上課中」、「下一堂課」、「今日課程已全部結束」或「今日尚無排定課程」狀態與教室、教授資訊，不觸發點擊跳轉行為，專注於資訊呈現。
  * **即時核心數據展示**：於總覽卡片底部即時呈現今日未完成待辦筆數、今日花費與累積畢業學分（`已排定 / 128`），分頁跳轉功能則統一由下方的「功能捷徑」卡片提供。
  * **今日摘要與待辦事項管理**：支援待辦事項的新增（名稱、備註、分類標籤、顏色圖示）、勾選完成狀態、刪除與一鍵重置，並透過 `SharedPreferences` 進行本地持久化儲存。
  * **學期資訊顯示**：於 AppBar 頂部以純文字靜態呈現當前學期（如 `113學年度 第 1 學期`），學期調整則由系統設定統一管理。
  * **功能捷徑網格**：提供一鍵前往課表、記帳本、行事曆與畢業審查的入口卡片，動態呈現本學期已排定門數與學分數。
  * **自適應響應式排版**：在手機端採單欄垂直捲動，在 Web/Windows 寬螢幕自動切換為左右雙欄與多格網格佈局。

### 2. `timetable_screen.dart` — 課程表 (`TimetableScreen`)
* **功能定位**：管理與檢視每週課程時間表。
* **目前狀態**：基礎頁面框架（包含支援窄螢幕開啟側邊欄的 `AppBar`），預留串接 `Course` 資料模型以呈現視覺化週課表網格。

### 3. `calendar_screen.dart` — 校園行事曆 (`CalendarScreen`)
* **功能定位**：整合校定重要日程、考試週期與個人活動行程。
* **目前狀態**：基礎頁面框架，預留實作月曆/週曆檢視與事件提醒清單。

### 4. `graduation_screen.dart` — 畢業審查 (`GraduationScreen`)
* **功能定位**：追蹤各類別學分（必修、選修、通識等）修習進度與畢業門檻達成率。
* **目前狀態**：基礎頁面框架，預留實作學分進度條、分類統計圖表與修課明細列表。

### 5. `expense_screen.dart` — 記帳本 (`ExpenseScreen`)
* **功能定位**：協助學生管理每月生活費預算、日常收支紀錄與消費分類統計。
* **目前狀態**：基礎頁面框架，預留實作收支登錄表單、月度預算儀表板與帳目清單。

### 6. `settings_screen.dart` — 系統設定 (`SettingsScreen`)
* **功能定位**：管理個人帳號、介面外觀、課表偏好、通知提醒、資料備份與版本資訊。
* **主要內容**：
  * **個人帳號與基本資料**：顯示頭像與身分標籤、即時編輯姓名（串接 Firebase Auth 與 Firestore 同步）、重設密碼信寄送、學系與學號設定。
  * **介面外觀與主題色調**：支援跟隨系統、淺色、深色主題模式切換，以及 7 款自訂主題代表色（靛藍、蔚藍、藍綠、紫羅蘭、暖橘、翠綠、櫻粉），全域響應並持久化儲存。
  * **課表與學業偏好**：當前學年度與學期修改（連動儀表板與課表）、週末課表（週六週日）顯示開關。
  * **通知與提醒**：上課前 10 分鐘通知、晨間待辦摘要通知、夜間記帳提醒開關。
  * **資料匯出與還原**：JSON 設定備份匯出、複製到剪貼簿、一鍵還原出廠預設值。
  * **系統資訊與登出**：平台環境與版本標籤、Firebase 狀態、安全登出帳號操作。

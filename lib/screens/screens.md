# `screens/` 畫面頁面目錄簡介

`screens/` 目錄存放 **UniTrack Pro** 的所有主要功能畫面（UI Screens）與身分驗證路由。所有主要功能分頁整合於主導覽列（`MainScreen`）中，並搭配 `ResponsiveLayout` 支援手機、平板與桌面端的自適應排版與動態導航。

---

## 目錄與畫面檔案結構一覽

```text
screens/
├── auth/                      # 會員身分驗證相關介面
│   ├── auth_gate.dart         # 身分驗證路由閘門（狀態流自動分流）
│   ├── login_screen.dart      # 會員登入畫面
│   └── register_screen.dart   # 會員註冊畫面
├── calendar_screen.dart       # 校園行事曆畫面
├── dashboard_screen.dart      # 首頁儀表板總覽畫面
├── expense_screen.dart        # 記帳本模組畫面
├── graduation_screen.dart     # 畢業學分審查畫面
├── settings_screen.dart       # 系統設定與個人偏好畫面
├── timetable_screen.dart      # 學期課程表核心畫面（即時同步與雙檢視模式）
└── screens.md                 # 畫面層設計規範與功能說明
```

## 頁面檔案詳情說明

### 一、身分驗證模組 (`screens/auth/`)

#### 1. `auth_gate.dart` — 身分驗證路由閘門 (`AuthGate`)
* **功能定位**：應用程式的根路由守衛（Route Guard）。
* **核心機制**：
  * 使用 `StreamBuilder<User?>` 監聽 `AuthService().authStateChanges` 狀態串流。
  * **載入中**：顯示質感的圓形進度指示器與提示。
  * **已登入**：自動解析使用者名稱或 Email 前綴，無縫導向主畫面 `MainScreen`。
  * **未登入 / 登出**：自動導向登入介面 `LoginScreen`。

#### 2. `login_screen.dart` — 會員登入畫面 (`LoginScreen`)
* **功能定位**：提供使用者輸入 Email 與密碼進行帳號登入。
* **主要特性**：
  * 支援表單驗證（Email 格式檢查、密碼非空檢查）。
  * 密碼能見度切換（眼睛圖示）與載入中按鈕防重複點擊。
  * 支援「忘記密碼」彈出對話框發送重設密碼信件。
  * 提供「尚未擁有帳號？立即註冊」快速跳轉按鈕。
  * 錯誤攔截器：將 Firebase 錯誤代碼轉換為友善繁體中文提示。

#### 3. `register_screen.dart` — 會員註冊畫面 (`RegisterScreen`)
* **功能定位**：新使用者建立帳號介面。
* **主要特性**：
  * 收集姓名/暱稱（選填）、入學年份（必填，支援民國年如 `112` 或西元年如 `2023` 格式驗證）、電子信箱、設定密碼與確認密碼。
  * 內建嚴謹的驗證規則（密碼至少 6 位、兩次密碼一致性校驗、入學年份合理區間檢查）。
  * 註冊成功後自動同步寫入 Firebase Auth Profile 與 Cloud Firestore 使用者基本資料文件。

### 二、核心功能畫面

#### 1. `dashboard_screen.dart` — 首頁總覽 (`DashboardScreen`)
* **功能定位**：使用者的個人化校園生活儀表板（Dashboard）。
* **主要內容**：
  * **今日校園生活總覽卡片**：串接 Cloud Firestore 即時課表資料流，自動根據當前系統時間與星期，純資訊動態呈現「上課中」、「下一堂課」、「今日課程已全部結束」或「今日尚無排定課程」狀態與教室、教授資訊，不觸發點擊跳轉行為，專注於資訊呈現。
  * **即時核心數據展示**：於總覽卡片底部即時呈現今日未完成待辦筆數、今日花費與累積畢業學分（`已排定 / 128`），分頁跳轉功能則統一由下方的「功能捷徑」卡片提供。
  * **今日摘要與待辦事項管理**：預設為乾淨的空待辦狀態（無內建假資料，並自動清理舊版遺留快取），支援待辦事項的新增（名稱、備註、分類標籤、顏色圖示）、勾選完成狀態、刪除與一鍵重置，並透過 `SharedPreferences` 進行本地持久化儲存。
  * **功能捷徑網格**：提供一鍵前往課表、記帳本、行事曆與畢業審查的入口卡片，動態呈現本學期已排定門數與學分數。
  * **自適應響應式排版**：在手機端採單欄垂直捲動，在 Web/Windows 寬螢幕自動切換為左右雙欄與多格網格佈局。

#### 2. `timetable_screen.dart` — 學期課程表 (`TimetableScreen`)
* **功能定位**：全功能學期課程排程與即時視覺化課表。
* **核心機制與特性**：
  * **Cloud Firestore 即時同步**：串接 `CourseService().getCoursesStream()`，課表增刪修皆秒級多裝置同步。
  * **雙檢視模式（手機/窄螢幕特化）**：
    * **單日時間軸模式 (`TimetableViewMode.daily`)**：按小時與節次條列選定日期的課程卡片、地點與起訖時間，提供橫向星期切換晶片。
    * **整週網格模式 (`TimetableViewMode.weekly`)**：專為手機螢幕最佳化直向欄寬，免橫向滑動即可一覽週一至週五網格。
  * **平板與桌面寬螢幕平鋪檢視**：以寬敞網格展示，左側提供節次序號與時間軸標記（如 `08:10 - 09:00`）。
  * **智慧當日高亮與日曆計算**：表頭自動計算顯示當週真實日期（如 `10/17 週五`），並以顯著高亮框標示今日所在欄位。
  * **彈性週末開關**：支援週一至週五（平日）與週一至週日（含週末）自由切換。
  * **課程完整 CRUD 管理**：
    * 支援手動新增課程、自訂課程色彩、教室地點、授課教授、星期、節次範圍、學分數與修別（必修/選修/通識）。
    * 衝堂防呆檢測：若選定時段與既有課程重疊，立即提示衝突資訊。
    * 點擊課程卡片即可開啟詳情對話框（AlertDialog），支援快速編輯、刪除與雲端復原。

#### 3. `settings_screen.dart` — 系統設定 (`SettingsScreen`)
* **功能定位**：管理個人帳號、外觀主題模式、通知提醒與系統版本資訊（寬螢幕 `>= 840px` 支援左右雙欄排版）。
* **主要內容**：
  * **個人帳號與基本資料**：顯示頭像與認證標籤、即時修改顯示名稱（串接 Firebase Auth 與 Firestore 同步）、寄送重設密碼信。
  * **介面外觀與主題模式**：支援跟隨系統、淺色模式、深色模式切換，全域即時響應並持久化儲存。
  * **通知與提醒通知**：上課前 10 分鐘課堂提醒、晨間待辦摘要提醒、夜間記帳提醒開關。
  * **系統狀態與版本 & 登出**：顯示應用程式版本、執行環境標籤、Firebase 雲端同步狀態與安全登出帳號操作。

#### 4. `calendar_screen.dart` — 校園行事曆 (`CalendarScreen`)
* **功能定位**：整合校定重要日程、考試週期與個人活動行程。
* **目前狀態**：基礎頁面框架（支援自適應導航），預留實作月曆/週曆檢視與事件提醒清單。

#### 5. `graduation_screen.dart` — 畢業審查 (`GraduationScreen`)
* **功能定位**：追蹤各類別學分（必修、選修、通識等）修習進度與畢業門檻達成率。
* **目前狀態**：基礎頁面框架，預留實作學分進度條、分類統計圖表與修課明細列表。

#### 6. `expense_screen.dart` — 記帳本 (`ExpenseScreen`)
* **功能定位**：協助學生管理每月生活費預算、日常收支紀錄與消費分類統計。
* **目前狀態**：基礎頁面框架，預留實作收支登錄表單、月度預算儀表板與帳目清單。
